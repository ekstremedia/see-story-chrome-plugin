# Privacy policy

**Clear View does not collect, transmit or sell any data.**

Effective 2026-08-26.

## What the extension can see

When you click the toolbar icon, Chrome grants the extension temporary access to
that one tab (the `activeTab` permission) so it can change how the page is
rendered. That access ends when you navigate away. The extension holds no
`host_permissions`, so it has no standing access to any website and cannot read
any page you have not clicked it on.

The page content it touches is never read out, copied, stored or sent anywhere.
There is no analytics, no telemetry, no crash reporting, no remote code and no
network request of any kind. The extension has no server.

## What is stored

Your own settings — the three toggles, the watch duration, and any per-site
rules you wrote — are stored with `chrome.storage.sync`. That is Chrome's own
storage, synchronised across your own Chrome profile by Google if you have
Chrome Sync turned on. The author cannot see it. Removing the extension removes
it.

## Third parties

None. Nothing is shared with anyone, because nothing is gathered.

## Changes

Any change to this policy will be committed to this repository, and its history
is public.
